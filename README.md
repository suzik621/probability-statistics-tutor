# probability-statistics-tutor

一个面向第一次学习概率论的大学生的 DSH skill：把“事件 → 随机变量 → 分布 → 数字特征 → 统计推断”串起来，讲概念、列公式、带例题、判题型、查错因。

内容对应 Kira 老师《概率论与数理统计》零基础精讲 73 集的九章框架，但表述、例题和模板为重新整理。

## 适用

- 第一次学概率论，想先建立直觉再看公式；
- 问一道具体题：古典概型、条件概率、分布函数、密度、期望方差、二维分布、大数定律、抽样分布、参数估计、区间估计、假设检验；
- 让 AI 检查解法、给提示，而不是直接要答案；
- 按期末/考研题型刷题、做错因诊断。

## 内容

- 九章知识地图与核心公式；
- 常见分布、抽样分布、置信区间、假设检验速查表；
- 每章一个典型例题；
- 二十条易错清单；
- 概念题/计算题/只给提示三种回答模板。

## 使用

把本仓库的 `SKILL.md` 放进 DSH 的 skills 目录，或按你使用的 agent 的 skill 加载方式导入。

触发词：学概率论、问一道概率题、帮我看看这个分布/期望/置信区间/假设检验。
